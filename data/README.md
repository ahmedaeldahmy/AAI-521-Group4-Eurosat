# Shared dataset metadata

Ahmed will add `split.csv` and `class_map.json` after checking and splitting EuroSAT RGB.

Do not upload the 27,000 original images into this repository. Download the dataset with the team's shared Colab code.

* `split.csv` lists every image path, its class number, class name, and whether it is train, val, or test. 
* `class_map.json` is the label key: the 10 class names, name-to-id, seed = 42, and the Zenodo source.
